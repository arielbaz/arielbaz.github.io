Tu ouvres un site d'actu et trois pop-ups te sautent au visage avant même la première ligne de texte. Ce n'est pas une fatalité : c'est juste que ton navigateur n'a pas de garde-fou.

**uBlock Origin** en est un, et probablement le meilleur. Gratuit, open source, sans compte, sans télémétrie — et surtout sans programme commercial caché.

## Ce qu'il fait vraiment

- **Bloque les publicités** sur les sites les plus saturés, y compris les formats vidéo intrusifs.
- **Neutralise les traqueurs** publicitaires et analytiques avant qu'ils ne chargent.
- **Allège la page** : moins de scripts, moins de données, donc un web plus rapide et une batterie qui souffre moins.
- **Reste discret** : aucun onglet « premium », aucune relance pour faire un don.

## Pourquoi il n'est pas interchangeable

Beaucoup d'extensions portent un nom proche, mais toutes ne jouent pas le même jeu. **AdBlock Plus**, par exemple, est bien open source — ce qui lui est reproché, c'est son programme *Acceptable Ads* : des publicités sont autorisées à passer… contre rémunération.

uBlock Origin, lui, ne négocie pas : par défaut, tout ce qui est pub est bloqué. C'est cette absence de compromis qui en fait la référence technique depuis des années.

:::tip Le Pro-Tip ARIBAZ — le piège de Manifest V3
Depuis le passage de Chrome au standard **Manifest V3**, la version historique d'uBlock Origin est bridée sur les navigateurs Chromium : Google limite l'accès aux API réseau qui la rendaient si puissante. Sur le Chrome Web Store, c'est donc **uBlock Origin Lite** qui est poussé — efficace, mais moins complet.

La version pleine et entière continue de tourner à 100 % sur **Firefox**. Si le blocage de publicités est important pour toi, c'est un argument sérieux en faveur du renard roux (ou de Brave, qui intègre son propre bloqueur directement dans le code du navigateur).
:::

## Mise en place (2 minutes)

1. Installe l'extension depuis le store de ton navigateur (Chrome Web Store, ou addons.mozilla.org pour Firefox).
2. Épingle l'icône dans la barre d'outils pour garder un œil sur le compteur de requêtes bloquées.
3. En cas de site cassé, clique sur l'icône puis sur le gros bouton d'alimentation : le blocage se désactive **uniquement pour ce site**.

## Verdict

C'est le premier geste à faire sur un ordinateur neuf, avant même d'installer un antivirus. Gratuit, léger, sans contrepartie : difficile de trouver une raison de s'en passer.
