Wizmage : naviguer sans voir les images qui traînent

Toutes les images floutées, un clic pour voir. Pour surfer sans les surprises que personne n'a demandées.

Tu veux un internet plus propre, sans tomber sur des images que tu n'as pas demandées ? Wizmage masque automatiquement toutes les images de ton navigateur, et te laisse les afficher une par une.

Comment ça marche

  • Toutes les images sont floutées dès l'activation.
  • La structure de la page est conservée : rien n'est cassé, les textes restent lisibles.
  • Un clic sur le bouton (ou ALT + A) affiche une image précise.
  • Personnalisable : choisis les sites où le filtre reste actif en permanence, ou seulement temporairement.

Installation

  1. Ouvre la fiche de l'extension sur le Chrome Web Store.
  2. Clique sur « Ajouter à Chrome » (ou au navigateur Chromium équivalent).
  3. C'est prêt : les images apparaissent floutées à la prochaine page chargée.
Le Pro-Tip ARIBAZ — deux corrections utiles

Le vocabulaire : on écrit « les images sont floutées ». « Flouer » veut dire escroquer — ce n'est pas tout à fait le même programme.

Firefox : le lien officiel mène au Chrome Web Store, qui ne fonctionne pas sur Firefox. Les utilisateurs du navigateur de Mozilla doivent chercher Wizmage directement sur addons.mozilla.org ou dans les modules complémentaires.

Enfin, garde en tête ce que l'outil ne fait pas : il ne filtre pas les contenus, il les cache. Ce n'est pas un substitut à un vrai filtre, et l'extension peut être désinstallée en deux clics — ce qui la rend utile contre les images surprises, pas contre un utilisateur déterminé.

Verdict

Pratique au travail, dans les transports ou sur un écran partagé. Un outil de confort visuel, à compléter par un filtrage réseau si l'enjeu est familial.
